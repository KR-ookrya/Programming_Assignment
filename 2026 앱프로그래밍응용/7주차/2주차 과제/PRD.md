# PRD — 개인 포트폴리오 웹사이트

## 1. 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | 개인 포트폴리오 웹사이트 |
| 버전 | v1.0 |
| 작성일 | 2026-04-08 |
| 작성자 | 홍길동 |

### 목적
자신의 기술, 프로젝트, 연락처를 한 페이지에서 보여주는 개인 포트폴리오 웹사이트를 제작한다.  
채용 담당자 또는 협업 파트너가 방문했을 때 개발자로서의 역량과 인상을 효과적으로 전달하는 것이 목표이다.

### 타겟 사용자
- 채용 담당자 / 인턴십 담당자
- 협업을 원하는 동료 개발자
- 포트폴리오를 검색하는 교수 또는 멘토

## 3. 페이지 구성 (섹션)

### 3.1 네비게이션 바
- 상단 고정 (fixed)
- 좌측: 이름 로고
- 우측: 소개 / 프로젝트 / 연락처 링크
- 스크롤 위치에 따라 현재 섹션 링크 강조

### 3.2 히어로 섹션
- 풀스크린 그라디언트 배경
- 인사말, 이름, 한 줄 소개 텍스트
- 프로젝트 보기 CTA 버튼

### 3.3 자기소개 (About)
- 2단 레이아웃: 텍스트 + 프로필 이미지
- 자기소개 문장 (2~3문단)
- 기술 스택 태그 목록

### 3.4 프로젝트 (Projects)
- 카드 그리드 레이아웃 (최소 3개)
- 각 카드: 아이콘, 제목, 설명, 기술 태그, GitHub/데모 링크
- 스크롤 시 페이드인 애니메이션

### 3.5 연락처 (Contact)
- 2단 레이아웃: 문의 폼 + 연락처 정보
- 폼 필드: 이름, 이메일, 메시지
- 폼 전송 시 완료 메시지 표시
- 이메일, GitHub, LinkedIn, 위치 정보 표시

### 3.6 푸터
- 저작권 표시

## 4. 기능 요구사항

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-01 | 네비게이션 클릭 시 해당 섹션으로 부드럽게 스크롤 | 높음 |
| F-02 | 스크롤 위치에 따라 현재 섹션 네비게이션 링크 강조 | 중간 |
| F-03 | 연락처 폼 유효성 검사 (필수 입력 항목) | 높음 |
| F-04 | 연락처 폼 전송 후 완료 메시지 표시 및 폼 초기화 | 높음 |
| F-05 | 프로젝트 카드 스크롤 페이드인 애니메이션 | 낮음 |
| F-06 | 모바일 반응형 레이아웃 지원 | 높음 |
