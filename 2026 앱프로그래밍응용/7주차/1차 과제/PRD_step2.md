# PRD Step 2 — 레시피 생성

## 개요
Step 1에서 추출한 재료 목록을 바탕으로 `qwen/qwen3.6-plus:free` 모델이 맞춤형 레시피를 생성한다.

## 목표
- 재료 목록 + 사용자 옵션을 입력으로 레시피 생성
- 구조화된 레시피 카드 형태로 결과 표시
- Step 3(저장)으로 연결

---

## 기능 요구사항

### FR-1 레시피 생성 옵션 입력
사용자가 레시피 생성 전 다음 옵션을 선택할 수 있다.

| 옵션 | 선택지 |
|------|--------|
| 요리 인원 | 1인 / 2인 / 3~4인 |
| 조리 시간 | 15분 이내 / 30분 이내 / 1시간 이내 |
| 음식 종류 | 한식 / 양식 / 일식 / 중식 / 무관 |
| 식이 제한 | 없음 / 채식 / 글루텐 프리 / 유제품 제외 |

### FR-2 레시피 생성 API 호출
- OpenRouter API (`qwen/qwen3.6-plus:free`) 호출
- 시스템 프롬프트: 재료와 옵션을 기반으로 레시피 JSON 반환 지시
- 사용자 프롬프트: Step 1 재료 목록 + FR-1 옵션 포함
- 응답 형식:
  ```json
  {
    "recipes": [
      {
        "title": "두부 당근 볶음",
        "description": "간단하고 건강한 한식 반찬",
        "servings": 2,
        "cookTime": "15분",
        "difficulty": "쉬움",
        "ingredients": [
          { "name": "두부", "amount": "1모" },
          { "name": "당근", "amount": "1개" }
        ],
        "steps": [
          "두부를 2cm 크기로 깍둑썰기한다.",
          "팬에 기름을 두르고 두부를 노릇하게 굽는다.",
          "당근을 채썰어 함께 볶고 간장으로 간한다."
        ],
        "tags": ["한식", "채식", "15분"]
      }
    ]
  }
  ```
- 레시피 3개 생성을 기본값으로 요청

### FR-3 레시피 카드 표시
- 레시피별 카드 UI (제목, 설명, 조리 시간, 난이도, 태그)
- 카드 클릭 시 상세 보기(재료 전체 + 단계별 조리법)
- "저장하기" 버튼으로 Step 3 연결

### FR-4 재생성
- "다른 레시피 추천받기" 버튼으로 동일 재료 + 옵션으로 재호출
- 이전 결과와 중복 방지 프롬프트 추가

---

## 비기능 요구사항
- 스트리밍 응답 지원 (`stream: true`) — 첫 글자부터 단계적으로 렌더링
- 생성 중 취소 버튼 제공
- 재료 중 인식 불확실 항목은 프롬프트에서 제외하거나 optional 표기

---

## UI 흐름

```
[재료 목록 요약] (Step 1에서 전달)
[옵션 선택 패널] — 인원 / 시간 / 종류 / 식이제한
        ↓ "레시피 생성" 버튼
[스트리밍 로딩 — 레시피 카드 순차 출현]
        ↓
[레시피 카드 3장]
  ┌──────────────────┐
  │ 두부 당근 볶음    │
  │ ⏱ 15분 | ★ 쉬움 │
  │ #한식 #채식      │
  │ [상세보기] [저장] │
  └──────────────────┘
[다른 레시피 추천받기]
```

---

## 기술 스택
| 항목 | 선택 |
|------|------|
| API 라우트 | Next.js Route Handler (`/api/recipe`) |
| 스트리밍 | `ReadableStream` + Server-Sent Events |
| 상태 전달 | React Context 또는 URL 쿼리 파라미터 |

---

## API 엔드포인트

### `POST /api/recipe`
**Request**
```json
{
  "ingredients": ["당근", "두부"],
  "options": {
    "servings": 2,
    "cookTime": "30분 이내",
    "cuisine": "한식",
    "dietary": "채식"
  },
  "excludeTitles": ["두부 당근 볶음"]
}
```
**Response** (스트리밍 JSON)
```json
{ "recipes": [...] }
```
