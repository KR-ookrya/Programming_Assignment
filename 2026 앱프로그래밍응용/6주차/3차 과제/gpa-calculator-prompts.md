## 단계 1. 계산 로직 구현

> 목표: GPA 계산 핵심 함수 + 졸업 가능 여부 판정 로직 완성

```
학점 관리 & 졸업 계산기 Python 모듈을 만들어줘.

파일: gpa_calculator.py

데이터 구조 (dataclass):
- GpaInput: 현재GPA, 이수학점, 졸업필요학점, 남은학기수,
            학기당이수학점, 목표GPA, 최저졸업기준GPA, 척도(4.5 or 4.0)
- Subject: 과목명, 학점수, 등급(A+/A/B+ 등 문자열)
- SemesterRecord: 학기이름, GPA
- GpaResult: 졸업가능여부, 목표달성가능여부,
             남은필요학점, 필요학기평균GPA, 예상최종GPA,
             이수율(%), 판정메시지

계산 로직:
1. 졸업 학점 충족 여부: 이수학점 + (학기당학점 × 남은학기) >= 졸업필요학점
2. 목표 GPA 달성용 필요 학기 평균:
   필요학기평균 = (목표GPA × 예상총학점 - 현재GPA × 이수학점) / (학기당학점 × 남은학기)
3. 판정: pass / warn / fail 3단계
4. 과목 목록에서 GPA 계산:
   GPA = sum(등급점수 × 학점수) / sum(학점수)
   등급 변환표 (4.5): A+=4.5, A=4.0, B+=3.5, B=3.0, C+=2.5, C=2.0, D+=1.5, D=1.0, F=0.0
   등급 변환표 (4.0): A+=4.0, A=3.5, B+=3.0, B=2.5, C+=2.0, C=1.5, D+=1.0, D=0.5, F=0.0

각 함수에 pytest 단위 테스트도 작성해줘.
```

## 단계 2. 웹 UI 구현

> 목표: 3탭 입력 폼 + 판정 결과 카드 + 이수율 진행 바 + 시나리오 테이블 완성

```
앞서 만든 gpa_calculator.py를 백엔드로 사용하는
웹앱을 만들어줘.

파일: app.py (FastAPI), templates/index.html

UI 요구사항:

[입력 영역 — 3탭 구조]
- 공통: 학점 척도 토글 버튼 (4.5 만점 / 4.0 만점)
- 탭 1 "직접 입력": 현재 GPA + 이수 학점 직접 입력
- 탭 2 "과목별 입력":
    과목명 / 학점수 / 등급(셀렉트) 행을 동적 추가/삭제
    하단에 "계산된 GPA: X.XX" 실시간 미리보기
    탭 활성 시 GPA 값을 계산 로직에 자동 반영
- 탭 3 "학기 기록":
    학기이름 / GPA 행을 동적 추가/삭제
    입력한 실제 기록은 라인 차트에 반영 (주황 실선)
- 등급 참고표 토글: ▶ 클릭 시 A+→4.5 등 변환표 펼치기

[졸업 정보 영역]
- 졸업 필요 총 학점, 남은 학기 수, 학기당 평균 이수 학점

[목표 설정 영역]
- 목표 졸업 GPA, 최저 졸업 기준 GPA

[결과 영역]
- 판정 배너 3종:
    ✅ 졸업 가능 + 목표 달성 가능 (초록)
    ⚠️ 졸업은 가능, 목표 GPA 어려움 (노랑)
    ❌ 졸업 기준 미달 (빨강)
- 이수율 진행 바: "X / 130학점 (N%)" 레이블 + 보라 그라데이션 바
- 스탯 카드 6개:
    현재GPA / 필요학기평균 / 남은학점 / 이수학점 / 예상총학점 / 남은학기
- 시나리오 테이블:
    현재유지 / 소폭향상 / 목표달성 / 최고학점 4가지 경우의
    학기GPA → 졸업최종GPA → 목표달성여부 표시

디자인: 보라색(#6366f1) 포인트, 카드 기반, 모바일 대응
```

## 단계 3. 그래프 시각화 추가

> 목표: Chart.js 그래프 2종 + 학기 히스토리 라인 추가 + 마무리 polish

```
index.html에 Chart.js 그래프 2개를 추가해줘.

그래프 1 — 라인 차트 (GPA 추이 시뮬레이션):
- x축: [학기 기록 탭의 실제 학기들] + 현재 + 1학기 후 + ... + N학기 후
- 4가지 라인:
    실제 기록 (주황 실선, 학기 기록 탭에 데이터 있을 때만 표시)
    현재 유지 (회색)
    목표 달성 경로 (보라, 면적 채우기)
    올 A+ 최고 경로 (초록 점선)
- y축 범위: min(현재GPA, 히스토리GPA) - 0.5 ~ 척도 만점

그래프 2 — 가로 막대 차트 (학점 이수 현황):
- 이수 완료 (보라) / 남은 필수 (연보라) / 초과 예상 (초록) 누적 표시
- x축 단위: 학점

공통 조건:
- 계산 버튼 클릭 시 두 그래프 동시 업데이트
- 페이지 최초 로드 시 기본값으로 자동 계산 및 그래프 렌더링
- 결과 영역으로 부드럽게 스크롤
```

## 단계별 실행 흐름

```
1단계 완료 → pytest로 계산 로직 검증 (과목별 GPA 계산 포함)
      ↓
2단계 완료 → uvicorn 실행 후 3탭 전환 + 이수율 바 + 판정 배너 확인
      ↓
3단계 완료 → 히스토리 라인 반영 + 그래프 동작 + 반응형 최종 확인
```
