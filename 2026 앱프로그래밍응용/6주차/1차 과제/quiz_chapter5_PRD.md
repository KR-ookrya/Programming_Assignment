## 1. 제품 개요

### 1.1 목적
웹 브라우저에서 즉시 실행 가능한 단일 HTML 파일 기반의 상식 퀴즈 게임을 제공한다.  
한국사·과학·지리·예술과 문화 4개 카테고리의 문제를 풀며 지식을 재미있게 습득할 수 있도록 한다.

### 1.2 대상 사용자
- 다양한 상식을 즐겁게 학습하고자 하는 일반 사용자
- 퀴즈 게임을 통해 경쟁하고 싶은 사용자
- 바이브 코딩 학습자 (코드 구조 학습 목적)

### 1.3 기술 제약
- 단일 HTML 파일 (외부 서버·DB 없음)
- 데이터 영속성: `localStorage` 사용
- 지원 환경: 모던 브라우저 (Chrome, Edge, Firefox, Safari 최신 버전)

## 4. 화면 구성

```
[공통 — 우측 상단 고정]
  └── 🌙/☀️ 테마 토글 버튼 (다크↔라이트)

[메인 메뉴]
  ├── 게임 모드 선택 (전체 / 카테고리 / 스피드)
  ├── 카테고리 선택 (카테고리 모드 선택 시 표시)
  ├── 게임 시작 버튼
  └── 리더보드 버튼

[게임 화면]
  ├── 상단 헤더: 진행도 / 점수 / 힌트 / 콤보 / 경과시간(분:초)
  ├── 전체·카테고리 모드 제한 시간 바 (10px 심플 바, 위에 모드명·남은 분:초 표시, 색상 변화)
  ├── 스피드 모드 문제당 타이머 바 (10px 심플 바, 위에 남은 초 텍스트 표시, 색상 변화)
  ├── 콤보 팝업
  ├── 문제 카드: 카테고리 · 문제 번호 · 문제 · 4지선다
  ├── 정답/오답 피드백 바 (오답 시 해설 포함)
  └── 하단: 힌트 버튼 / 나가기 버튼

[결과 화면]
  ├── 정답률 링 차트
  ├── 통계: 정답 수 / 점수 / 최대 콤보 / 총 소요 시간
  ├── 닉네임 입력 & 저장
  └── 다시 도전 / 메인 메뉴 / 리더보드 버튼

[리더보드]
  ├── TOP 10 순위 목록
  └── 기록 초기화 버튼
```

### ① STEP 1 — 기본 구조 설계 및 게임 화면 구현

| 항목 | 내용 |
|------|------|

| 추가 항목 | F-01 ~ F-12, F-16 ~ F-19 |

**클로드 지시 사항**
```
혼자 공부하는 바이브 코딩 with 클로드 코드 책의 chapter 5 퀴즈 프로그램을 HTML로 만들어줘.
- 외부 서버 없이 단일 HTML 파일로 실행 가능해야 해
- 게임 모드: 전체 도전(40문제) / 카테고리 도전(10문제) / 스피드 퀴즈(15초 제한·20문제)

- 다크 테마 + 반응형 디자인
```

### ② STEP 2 — 타이머 고도화 + 모드별 제한 시간 바

| 항목 | 내용 |
|------|------|
| 결과물 | 경과 시간 헤더 표시 + 스피드 모드 타이머 바 + 전체·카테고리 모드 제한 시간 바 (v2.5에서 심플화) |
| 핵심 변화 | 심플 10px 바 + 바 위 텍스트 라벨, 전체/카테고리 모드 제한 바 신규 추가 |
| 제한 시간 | 전체 모드 5분 초과 → "⏰ 시간 초과!" / 카테고리 모드 3분 초과 → "❌ 실패!" |
| 추가 항목 | F-13, F-14, F-15, F-27, F-28, F-29 |

**클로드 지시 사항**
```
시간 타이머 할 때 시간이 몇 분 몇 초 지났는지 사용자에게 보이게 바꿔줘.
- 게임 헤더에 경과 시간을 0:00 형식으로 실시간 표시

시간을 나타내는 막대기가 시간에 따라 줄어들어서
사용자가 얼마나 시간이 지났는지 한눈에 알아볼 수 있게 만들어줘.
- 타이머 바를 굵게 만들고 눈금 표시
- 바 안에 남은 시간을 숫자로 표시
- 시간이 줄수록 색상을 초록 → 노랑 → 빨강으로 변경
- 5초 이하에서는 숫자를 크게 + 발광 효과

전체 모드를 선택해서 퀴즈를 할 때 시간이 10분 이상이 되면
"시간 초과" 알림과 함께 퀴즈가 꺼지는 기능을 추가해줘.
카테고리 도전 모드일 때는 5분이 이상이 되면 "실패" 알림과 함께
퀴즈가 꺼지는 기능도 추가해줘.
전체 모드·카테고리 도전 모드에서 시간을 한눈에 알 수 있는
막대기도 추가해줘.
```

