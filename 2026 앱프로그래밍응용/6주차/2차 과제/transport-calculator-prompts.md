# 교통비 계산기 — Claude Code 3단계 프롬프트

PRD 기반으로 Claude Code에 순서대로 붙여넣어 사용하세요.

---

## 단계 1. 계산 로직 구현

> 목표: 핵심 계산 함수와 데이터 구조 완성

```
교통비 계산기 Python 모듈을 만들어줘.

파일: calculator.py

요구사항:
- 입력값: 1회 요금(원), 하루 이용 횟수, 월 이동일, 학기 주 수
- 출력값: 월 교통비, 학기 교통비, 연간 교통비

K-패스 할인 로직:
- 월 15회 이상 이용 시에만 적용
- 일반 20% / 청년(19~34세) 30% / 저소득층 53% 환급
- 할인 전 금액과 할인 후 금액 모두 반환

반환 형식은 dataclass로 정의하고,
각 함수에 단위 테스트(pytest)도 같이 작성해줘.
```

---

## 단계 2. 웹 UI 구현

> 목표: 입력 폼 + 결과 카드 HTML 완성

```
앞서 만든 calculator.py를 백엔드로 사용하는
단일 파일 웹앱을 만들어줘.

파일: app.py (FastAPI), templates/index.html

UI 요구사항:
- 입력: 요금, 하루 횟수, 월 이동일, 학기 주 수
- 프리셋 버튼: 시내버스 1400원 / 지하철 1500원 / 광역버스 2000원
- K-패스 체크박스 → 체크 시 유형 선택(일반/청년/저소득층) 노출
- 결과 카드 4개: 월 이용 횟수 / 월 원금 / 월 실부담 / 학기 예상
- K-패스 적용 시 "월 N원 절약 · 연간 N원 환급" 배너 표시

디자인: 보라색(#6366f1) 포인트 컬러, 카드 기반 레이아웃, 모바일 대응
```

---

## 단계 3. 그래프 시각화 추가

> 목표: Chart.js 기반 그래프 2종 추가 + 마무리 polish

```
index.html에 Chart.js 그래프 2개를 추가해줘.

그래프 1 — 막대 차트:
- x축: 월 원금 / 월 실부담 / 학기 원금 / 학기 실부담
- 원금은 회색(#cbd5e1), 실부담은 보라색(#6366f1)으로 구분
- y축 단위: 만원

그래프 2 — 도넛 차트:
- 한 달 기준 "실부담 교통비 vs K-패스 환급액" 비율
- K-패스 미적용 시 단색으로 표시

공통 조건:
- 계산 버튼 클릭 시 그래프 즉시 업데이트
- 페이지 최초 로드 시 기본값으로 자동 계산
- 그래프 → 결과 카드 순으로 부드럽게 스크롤
```

## 단계별 실행 흐름

```
1단계 완료 → pytest로 계산 로직 검증
      ↓
2단계 완료 → uvicorn 실행 후 브라우저 확인
      ↓
3단계 완료 → 그래프 동작 및 반응형 레이아웃 최종 확인
```

## 추가 프롬프트 (필요 시)

| 상황 | 프롬프트 |
|------|---------|
| 결과가 이상할 때 | `"계산 결과 예시: 요금 1400원 × 4회 × 22일 = 123,200원 이어야 해"` |
| 디자인 수정 | `"카드 간격 좁히고 모바일에서 2열 → 1열로 변경해줘"` |
| 기능 추가 | `"따릉이 월정액 5,000원 옵션도 추가해줘"` |
