**바이브 코딩(Vibe Coding)**은
설계 문서나 복잡한 기획 없이, “감(느낌, 분위기)”대로 빠르게 만들면서 개선해가는 개발 방식이야.

🔹 특징

계획보다 실행

완벽한 설계 없이 바로 코드 작성

빠른 피드백

실행 → 수정 → 실행 반복

감성/사용자 느낌 중시

UX, 디자인, 흐름을 직접 써보면서 조정

🔹 예시

예를 들어 웹사이트 만든다고 하면:

❌ 전통 방식: 기획서 → 설계서 → DB 구조 → 개발

✅ 바이브 코딩:
“일단 로그인 화면부터 만들어보자” → 버튼 눌러보고 → 이상하면 고침

- 장점

 - 빠르게 결과물 나옴

- 창의적인 아이디어 많이 나옴

- 개인 프로젝트에 좋음

- 단점

- 코드 구조 엉망될 수 있음

- 나중에 유지보수 힘듦

- 팀 프로젝트에선 충돌 많음
