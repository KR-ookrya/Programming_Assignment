# 🌐 나의 바이브 코딩 웹사이트

## 📌 프로젝트 소개
이 프로젝트는 대학 수업에서 진행한 **바이브 코딩 과제**로, HTML과 CSS를 활용하여 만든 간단한 개인 웹사이트입니다.

웹 개발의 기초를 이해하고, 직접 웹페이지를 구성해보는 것을 목표로 제작되었습니다.

---

## 🧑‍💻 주요 기능
- ✅ 기본적인 웹페이지 구조 (Header, Navigation, Footer)
- ✅ 자기소개 섹션
- ✅ 프로필 사진 표시
- ✅ 연락처 정보 제공

---

## 🖼️ 화면 구성
### 1. 홈(Home)
- 간단한 인사말
- 프로필 사진 표시

### 2. 자기소개(About)
- 이름, 전공, 관심 분야 소개
- 향후 목표 및 학습 방향 설명

### 3. 연락(Contact)
- 이메일 정보 제공

---

## 🛠️ 사용 기술
- HTML5
- CSS3
