# 🎮 클릭 게임 사이트

## 📌 사이트 소개
이 웹사이트는 HTML, CSS, JavaScript를 활용하여 제작한 간단한 클릭 게임입니다.  
사용자는 제한된 시간 동안 버튼을 클릭하여 최대한 높은 점수를 얻는 것을 목표로 합니다.

## 🎯 주요 기능
- 버튼 클릭 시 점수 증가
- 10초 제한 타이머
- 실시간 점수 및 남은 시간 표시
- 게임 종료 시 최종 점수 알림

## 🛠 사용 기술
- HTML5
- CSS3 (버튼 디자인, 애니메이션 효과)
- JavaScript (이벤트 처리, 타이머 기능)

## 💡 특징
- 직관적인 UI로 누구나 쉽게 플레이 가능
- 간단한 구조로 웹 개발 입문자에게 적합
- 게임 요소를 통해 재미와 학습을 동시에 제공

## ▶️ 실행 방법
1. HTML 파일을 다운로드
2. 파일을 더블 클릭하여 브라우저에서 실행
3. "게임 시작" 버튼 클릭 후 게임 플레이

## 📚 활용 목적
- 웹 개발 기초 학습
- JavaScript 이벤트 처리 이해
- 대학교 과제 제출용
