# ☕ My Cafe - 카페 랜딩 페이지

## 📌 사이트 소개

이 웹사이트는 HTML, CSS, JavaScript를 활용하여 제작한 간단한 카페 랜딩
페이지입니다.\
사용자에게 카페의 분위기와 대표 메뉴를 소개하는 목적을 가지고 있습니다.

## 🎯 주요 기능

-   감성적인 배경 이미지가 적용된 메인 화면
-   카드 형태의 메뉴 UI (아메리카노, 카페라떼, 티라미수)
-   버튼 클릭 시 주문 완료 알림 기능 (JavaScript 사용)

## 🛠 사용 기술

-   HTML5
-   CSS3 (Flexbox, 그림자 효과, 반응형 레이아웃)
-   JavaScript (간단한 이벤트 처리)

## 💡 특징

-   깔끔하고 직관적인 디자인
-   초보자도 이해하기 쉬운 구조
-   실제 카페 사이트처럼 구성된 UI

## ▶️ 실행 방법

1.  HTML 파일을 다운로드
2.  파일을 더블 클릭하여 브라우저에서 실행

## 📚 활용 목적

-   웹 개발 입문 연습
-   대학교 과제 제출용
-   UI/UX 기초 학습
