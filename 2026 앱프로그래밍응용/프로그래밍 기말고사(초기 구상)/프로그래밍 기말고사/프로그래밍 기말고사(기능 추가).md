## AI 자기소개서 첨삭 앱 — 최종 구현 내용



### 사이트 소개

취업을 준비하는 학생들이 자기소개서를 작성하면, Claude AI(Anthropic)가 전문 컨설턴트처럼 심층 분석하여 즉각적인 피드백을 제공하는 웹 서비스입니다.
별도의 로그인이나 비용 없이 자기소개서를 붙여넣기만 하면 점수, 개선점, 첨삭본까지 한 번에 받아볼 수 있습니다.



### AI가 제공하는 첨삭 결과 구성

| 항목 | 내용 |
|------|------|
| 종합 평가 | 자기소개서의 전반적인 수준과 첫인상을 3~4문장으로 평가 |
| 점수 | 100점 만점 (내용의 구체성 / 문장 표현력 / 직무 적합성 / 차별화 포인트 각 25점) |
| 잘된 점 | 긍정적인 요소를 항목별로 정리 |
| 개선이 필요한 부분 | 문제점과 구체적인 수정 방법 제시 |
| 첨삭된 자기소개서 | 수치·성과 중심으로 개선된 완성본 직접 제공 |



### 구현된 기능 목록

#### 핵심 기능
* **AI 첨삭 분석** : 자기소개서 본문을 입력하면 Claude AI가 5가지 항목으로 나누어 상세한 피드백 제공
* **실시간 스트리밍 출력** : 분석 결과가 타이핑되듯 실시간으로 화면에 출력됨 (Server-Sent Events 방식)
* **직무 / 회사 맞춤 첨삭** : 지원 직무와 회사명을 함께 입력하면 해당 맥락에 맞는 맞춤형 피드백 제공

#### 추가 구현 기능
* **글자 수 경고** : 자기소개서 입력 중 권장 글자 수(1,000자)를 초과하면 실시간으로 경고 메시지 표시
* **예시 자기소개서 불러오기** : 버튼 클릭 한 번으로 샘플 자기소개서가 자동 입력되어 바로 테스트 가능
* **PDF 저장** : 첨삭 결과를 PDF 파일로 저장 가능, 직무·회사·생성 날짜가 헤더에 포함됨
* **추가 질문하기** : 첨삭 결과를 받은 후 AI에게 후속 질문 가능 (예: "3번 항목만 다시 써줘"), 이전 대화 맥락이 유지됨
* **결과 복사** : 첨삭 결과 전체를 클립보드에 한 번에 복사
