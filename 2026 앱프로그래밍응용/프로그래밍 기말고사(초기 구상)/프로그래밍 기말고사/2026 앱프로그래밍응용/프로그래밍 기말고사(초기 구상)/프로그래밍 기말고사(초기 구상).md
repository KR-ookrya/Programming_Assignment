##### 주제 3가지

AI 자기소개서 첨삭 앱 , 과제 요약 앱 , AI 일정 생성 앱



##### 각 주제의 목적

* AI 자기소개서 첨삭 앱 :  학생들이 이 앱을 사용하여 시간과 비용 없이 즉각적인 피드백을 받아 자기소개서의 완성도를 높이기 위해
* 과제 요약 앱 :  AI 요약 기능을 활용하여 학습 시간을 줄이고 중요 내용을 효율적으로 이해하는 것을 돕기 위해
* AI 일정 생성 앱 : 자동으로 일정을 구성 하여 시간 관리를 효율적으로 관리 하기 위해



---

##### 최종 선택 주제

**AI 자기소개서 첨삭 앱**



##### 사이트 설명

Claude AI(Anthropic)를 활용하여 자기소개서를 자동으로 분석하고 전문적인 피드백을 제공하는 웹 애플리케이션이다. 사용자가 자기소개서를 입력하면 AI가 실시간으로 점수와 개선 방향, 첨삭된 완성본을 스트리밍 방식으로 출력해준다. 지원 직무와 회사를 함께 입력하면 해당 맥락에 맞는 맞춤형 첨삭이 제공된다.

**기술 스택**
* 백엔드 : Node.js + Express.js
* AI 모델 : Claude Opus 4.7 (Anthropic API)
* 스트리밍 방식 : Server-Sent Events (SSE)
* 프론트엔드 : HTML / CSS / JavaScript (Vanilla)
* 히스토리 저장 : localStorage (브라우저)



##### 구현된 기능 목록

**핵심 기능**

* AI 첨삭 : Claude Opus AI가 자기소개서를 심층 분석하여 종합 평가, 100점 만점 점수, 잘된 점, 개선 방향, 첨삭 완성본을 제공
* 실시간 스트리밍 출력 : 분석 결과를 타이핑되듯 실시간으로 화면에 출력 (SSE 방식)
* 직무 / 회사 맞춤 첨삭 : 지원 직무와 회사명을 입력하면 해당 맥락에 맞는 피드백 제공

**추가 기능**

* 글자 수 실시간 카운트 : 권장 글자 수(1,000자) 초과 시 경고 표시
* 예시 자기소개서 불러오기 : 샘플 데이터를 클릭 한 번으로 자동 입력
* 추가 질문하기 : 첨삭 결과를 바탕으로 AI에게 후속 질문 가능
* 결과 복사 : 첨삭 결과 전체를 클립보드에 복사
* PDF 저장 : 첨삭 결과를 PDF 파일로 인쇄 및 저장
* 단축키 지원 : Ctrl + Enter로 첨삭 시작 및 질문 전송

**사용성 개선 기능**

* 첨삭 히스토리 : 최근 10개의 첨삭 결과를 브라우저(localStorage)에 자동 저장하고, 클릭 한 번으로 이전 결과 복원 가능. 개별 삭제 및 전체 삭제 지원
* 항목별 집중 첨삭 : 지원동기 / 성장과정 / 직무역량·경험 / 입사 후 포부 중 원하는 항목을 선택하면 해당 항목에 집중한 맞춤 첨삭 제공
* 영문 번역 : 첨삭된 자기소개서를 전문적인 영어로 번역. 해외 기업이나 글로벌 직군 지원 시 활용 가능



##### 첨삭 결과 구성 (5단계)

1. 종합 평가 — 자기소개서의 전반적인 수준과 첫인상
2. 점수 (100점 만점) — 내용의 구체성 / 문장 표현력 / 직무 적합성 / 차별화 포인트 각 25점
3. 잘된 점 — 긍정적인 요소 목록
4. 개선이 필요한 부분 — 문제점과 구체적 해결 방법
5. 첨삭된 자기소개서 — 수치·성과 중심으로 개선된 완성본



##### API 구성

* POST /api/analyze — 자기소개서 첨삭 요청 (직무, 회사, 항목 선택 포함)
* POST /api/followup — 첨삭 결과에 대한 후속 질문
* POST /api/translate — 첨삭된 자기소개서 영문 번역
