● PRD: 개인 할 일 관리 앱

  ---
  1. 개요

  제품명: Todo Manager
  목적: 하루 10~20개의 할 일을 카테고리별로 관리하고 진행률을 확인하는 개인용 웹 앱
  플랫폼: 브라우저 (단일 HTML 파일, 순수 JS)
  데이터 저장: localStorage (새로고침 후에도 유지)

  ---
  2. 사용자 스토리

  ┌─────┬──────────────────────────────────────────┐
  │  #  │              사용자 스토리               │
  ├─────┼──────────────────────────────────────────┤
  │ 1   │ 할 일을 빠르게 추가하고 싶다             │
  ├─────┼──────────────────────────────────────────┤
  │ 2   │ 내용이나 카테고리를 나중에 수정하고 싶다 │
  ├─────┼──────────────────────────────────────────┤
  │ 3   │ 완료한 항목을 체크로 구분하고 싶다       │
  ├─────┼──────────────────────────────────────────┤
  │ 4   │ 업무/개인/공부로 분류해서 보고 싶다      │
  ├─────┼──────────────────────────────────────────┤
  │ 5   │ 오늘 얼마나 했는지 진행률을 보고 싶다    │
  ├─────┼──────────────────────────────────────────┤
  │ 6   │ 필요 없는 항목은 삭제하고 싶다           │
  └─────┴──────────────────────────────────────────┘

  ---
  3. 기능 요구사항

  3.1 할 일 관리 (CRUD)

  - 추가: 텍스트 입력 + 카테고리 선택 후 엔터/버튼으로 추가
  - 수정: 항목 클릭 시 인라인 편집 (텍스트, 카테고리 변경 가능)
  - 삭제: 항목별 삭제 버튼
  - 완료 체크: 체크박스 클릭 → 취소선 표시, 완료 상태 토글

  3.2 카테고리

  - 3가지 고정 카테고리: 업무 / 개인 / 공부
  - 카테고리별 필터링 탭 (전체 포함 총 4개 탭)
  - 각 항목에 카테고리 배지 표시

  3.3 진행률

  - 상단에 전체 진행률 표시 (완료 수 / 전체 수, % 프로그레스 바)
  - 카테고리별 완료 수 요약 (예: 업무 3/5)

  3.4 데이터 영속성

  - 모든 변경사항 즉시 localStorage 저장
  - 페이지 로드 시 자동 복원

● 체크리스트 
   1. 새로고침해도 데이터 유지되는가
   2. 추가 / 수정 / 삭제 정상 동작하는가
   3. 카테고리 필터 탭이 잘 작동하는가
   4. 진행률 바가 즉시 갱신되는가
   5. 모바일에서 레이아웃이 깨지지 않는가
