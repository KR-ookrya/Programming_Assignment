## 1. 제품 개요

### 한 줄 요약

사용자가 영화 제목을 입력하면 TMDB API를 통해 포스터·별점·줄거리를 즉시 검색할 수 있는 단일 파일 웹 앱

### 제품 설명

MOVIEFIND는 별도의 서버·빌드 환경 없이 브라우저에서 바로 실행되는 정적 영화 검색 웹 애플리케이션입니다.
TMDB API 키를 한 번 입력하면 이후 재입력 없이 자유롭게 영화를 검색하고, 카드 형태로 결과를 확인하며, 클릭 시 상세 정보를 팝업으로 볼 수 있습니다.

HTML · CSS · Vanilla JS만으로 구성되어 있어 대학 수업 과제, 포트폴리오, 프론트엔드 학습 프로젝트에 적합합니다.

## 3. 사용자 정의

### 주요 사용자 — 프론트엔드 학습자 (대학생)

HTML/CSS/JS 기초를 익히고 외부 API 연동을 처음 경험하는 학습자.
파일을 브라우저로 열기만 하면 즉시 사용할 수 있는 간단함을 기대한다.

### 부가 사용자 — 영화 정보 검색 일반 사용자

보고 싶은 영화의 포스터, 별점, 줄거리를 빠르게 확인하려는 일반 사용자.
기술 배경 없이도 검색창 하나로 원하는 정보를 얻는다.

## 4. 기능 요구사항

### FR-01. API 키 관리 `필수`

- 사용자는 TMDB API 키를 입력창에 입력하고 저장 버튼으로 등록할 수 있다.
- 저장된 키는 `localStorage`에 보관되며, 새로고침 후에도 자동으로 불러온다.
- 키가 없는 상태에서 검색 시 "API 키를 입력해주세요" 안내 메시지를 표시한다.
- 401 응답 수신 시 "API 키가 유효하지 않습니다" 오류 메시지를 표시한다.

### FR-02. 영화 검색 `필수`

- 검색창에 영화 제목을 입력하고 **검색 버튼** 또는 **Enter 키**로 검색을 실행한다.
- TMDB `/search/movie` 엔드포인트에 `language=ko-KR` 파라미터로 요청하여 한국어 결과를 반환한다.
- 검색 결과가 없을 경우 "검색 결과가 없습니다" 메시지를 표시한다.
- 검색 중에는 로딩 스피너를 표시하고 완료 후 결과 건수를 상태 바에 표시한다.

### FR-03. 결과 카드 목록 `필수`

- 검색 결과를 반응형 그리드 형태로 렌더링한다. (최소 180px, auto-fill)
- 각 카드에는 **포스터 이미지, 제목, 개봉 연도, 별점(★)** 을 표시한다.
- 포스터가 없는 경우 "포스터 없음" 대체 텍스트 영역을 표시한다.
- 카드에 마우스를 올리면 위로 이동하는 hover 애니메이션을 제공한다.

### FR-04. 상세 정보 모달 `필수`

- 카드를 클릭하면 해당 영화의 상세 정보를 표시하는 모달 팝업을 표시한다.
- 모달에는 **포스터, 제목, 원제, 개봉 연도, 별점, 평가 수, 언어, 줄거리**를 포함한다.
- 모달은 닫기(×) 버튼, 배경(오버레이) 클릭, ESC 키 세 가지 방법으로 닫을 수 있다.
- 모달이 열린 동안 페이지 스크롤은 잠근다.

### FR-05. 상태 및 오류 피드백 `권장`

- 검색 중 — 3개의 점이 위아래로 움직이는 스피너를 표시한다.
- 검색 완료 — 검색어와 결과 건수를 상태 바에 표시한다.
- 오류 발생 — 메시지를 붉은색으로 강조하여 표시한다.
- API 키 저장 성공 — 안내 메시지를 상태 바에 표시한다.

## 5. 비기능 요구사항

| 항목 | 요구사항 |
|------|----------|
| **성능** | 검색 버튼 클릭 후 API 응답 수신까지 네트워크 지연 외 추가 렌더링 지연 없음 |
| **호환성** | Chrome, Edge, Firefox, Safari 최신 버전에서 정상 동작 |
| **반응형** | 320px 이상 모든 화면 너비에서 레이아웃 깨짐 없이 표시 (모바일 모달 세로 배치 지원) |

| **무설치** | Node.js, npm, 빌드 도구 없이 브라우저에서 파일을 직접 열어 실행 가능 |
| **접근성** | 이미지에 alt 텍스트 제공, 키보드(Enter, ESC)로 주요 기능 조작 가능 |

## 6. UX 플로우

### 최초 사용
```
앱 접속 → API 키 입력 → 저장 클릭 → 검색어 입력 → 결과 확인 → 카드 클릭 → 모달
```

### 재방문
```
앱 접속 → API 키 자동 로드 → 검색어 입력 → 결과 확인
```

### 오류 발생
```
검색 요청 → API 오류 (401 / 네트워크) → 오류 메시지 표시 → 사용자 키 재입력
```

## 8. API 명세

### 엔드포인트

```
GET https://api.themoviedb.org/3/search/movie
    ?api_key={KEY}
    &query={검색어}
    &language=ko-KR
    &include_adult=false
```

### 요청 파라미터

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| `api_key` | string | 필수 | TMDB v3 API 키 |
| `query` | string | 필수 | 검색할 영화 제목 (URL 인코딩 적용) |
| `language` | string | 선택 | 응답 언어. `ko-KR` 고정 |
| `include_adult` | boolean | 선택 | 성인 콘텐츠 포함 여부. `false` 고정 |

### 응답 주요 필드

| 필드 | 타입 | 사용처 |
|------|------|--------|
| `title` | string | 카드·모달 제목 |
| `original_title` | string | 모달 원제 |
| `poster_path` | string \| null | 포스터 이미지 경로 |
| `release_date` | string | 개봉 연도 (앞 4자리) |
| `vote_average` | number | 별점 (소수점 1자리) |
| `vote_count` | number | 평가 수 |
| `overview` | string | 줄거리 |
| `original_language` | string | 원본 언어 배지 |

### 포스터 이미지 URL

```
https://image.tmdb.org/t/p/w500{poster_path}
```

> `poster_path`가 null이면 "포스터 없음" 대체 텍스트를 표시한다.

## 10. 범위

### In Scope (포함)

- 영화 제목 키워드 검색
- 검색 결과 카드 그리드 표시
- 영화 상세 정보 모달
- API 키 localStorage 저장
- 로딩 상태 및 오류 메시지
- 반응형 레이아웃 (모바일 지원)

### Out of Scope (제외)

- 회원가입 / 로그인
- 즐겨찾기 / 찜 목록
- 페이지네이션
- 장르·연도 필터
- 트레일러 영상 재생
- 서버 사이드 렌더링

## 11. 리스크

| 리스크 | 영향 | 대응 방안 |
|--------|------|-----------|
| TMDB API 키 미발급 | 앱 사용 불가 | 화면 내 발급 안내 배너 + 링크 제공 |
| API 요청 한도 초과 | 검색 실패 | TMDB 무료 플랜은 초당 50건 제한 — 일반 사용 수준에서 문제 없음 |
| 한국어 데이터 미비 | 일부 영화 정보 영문 표시 | TMDB 한국어 번역 커버리지에 의존. 원제 병기로 보완 |
| CORS 이슈 | 로컬 파일에서 API 호출 불가 | TMDB API는 브라우저 직접 호출을 허용 (CORS 허용 헤더 포함) |
