## 1. 개요 (Overview)

### 1.1 제품 한 줄 설명
도시명 또는 현재 위치를 기반으로 실시간 날씨 정보와 5일 예보를 제공하는 웹 애플리케이션.

### 1.2 배경 및 목적
- 기상청이나 포털 날씨 서비스는 광고·복잡한 UI로 핵심 정보 접근이 불편함
- 단일 HTML 파일로 서버 없이 누구나 바로 실행할 수 있는 가벼운 날씨 앱이 필요
- OpenWeatherMap 무료 API를 활용해 대학생 수준에서 API 연동 학습 목적으로도 활용 가능

### 1.3 목표
| 목표 | 측정 기준 |
|---|---|
| 핵심 날씨 정보를 한 화면에 표시 | 현재 날씨 + 상세 정보 + 5일 예보 한 페이지 노출 |
| 빠른 재검색 경험 제공 | 최근 검색어 클릭 1회로 재조회 가능 |
| 단일 파일로 실행 | 별도 서버·빌드 도구 없이 브라우저 직접 실행 |

## 4. 기능 명세 (Features)

### 4.1 핵심 기능 (MVP)

#### F-01. 도시명 검색
- 텍스트 입력 후 검색 버튼 또는 `Enter` 키로 조회
- 입력값: 영문 도시명 (예: `Seoul`, `Tokyo`, `New York`)
- 오류 처리: 존재하지 않는 도시 → "도시를 찾을 수 없습니다." 메시지 표시

#### F-02. 현재 날씨 표시
| 항목 | 출처 |
|---|---|
| 도시명 + 국가 코드 | API `name`, `sys.country` |
| 날씨 아이콘 (이모지) | API `weather[0].main` → 이모지 매핑 |
| 현재 기온 | API `main.temp` |
| 체감 기온 | API `main.feels_like` |
| 날씨 설명 | API `weather[0].description` |

#### F-03. 상세 기상 정보
| 항목 | 출처 |
|---|---|
| 습도 | `main.humidity` (%) |
| 풍속 | `wind.speed` (m/s) |
| 구름량 | `clouds.all` (%) |
| 최저 기온 | `main.temp_min` |
| 최고 기온 | `main.temp_max` |
| 가시거리 | `visibility` (m → km 변환) |

#### F-04. 일출 / 일몰 시간
- `sys.sunrise`, `sys.sunset` (Unix timestamp) + `timezone` offset → 현지 시간 변환 후 표시

#### F-05. 5일 예보
- OpenWeatherMap Forecast API (3시간 간격 40개 데이터)
- 하루 1개(정오 12:00 기준) 추출 → 날짜 / 아이콘 / 기온 / 날씨 설명 표시
- 오늘 날짜는 제외, 이후 5일 표시
- 가로 스크롤 레이아웃

---

### 4.2 편의 기능

#### F-06. 현재 위치 자동 감지
- 📍 버튼 클릭 → `navigator.geolocation.getCurrentPosition()` 호출
- 위도·경도로 API 호출 (`lat=`, `lon=` 파라미터)
- 위치 권한 거부 시: "위치 정보를 가져올 수 없습니다." 에러 표시

#### F-07. 최근 검색 기록
- 검색 성공 시 `localStorage`에 도시명 저장 (최대 6개)
- 중복 제거 (대소문자 무시), 최신 항목이 앞에 위치
- 태그 형태로 표시, 클릭 시 즉시 재검색

#### F-08. 기온 단위 전환 (°C / °F)
- 우측 상단 토글 버튼 또는 온도 숫자 클릭으로 전환
- 전환 시 화면의 모든 기온 값 즉시 갱신 (API 재호출 없음)
- 변환 공식: `°F = °C × 9/5 + 32`

#### F-09. 날씨별 배경 그라디언트
| 날씨 | 배경 테마 |
|---|---|
| Clear (맑음) | 파란 계열 (낮 하늘) |
| Clouds (흐림) | 회청 계열 |
| Rain / Drizzle | 짙은 파란 계열 |
| Thunderstorm (뇌우) | 어두운 회색-갈색 |
| Snow (눈) | 밝은 청록 계열 |
| Fog / Mist / Haze | 짙은 회색 |

### 4.3 비기능 요구사항

| 항목 | 요구사항 |
|---|---|
| 성능 | 현재 날씨 + 예보 API를 `Promise.all`로 병렬 호출 |
| 보안 | API 키는 클라이언트 코드에 직접 입력 (학습용, 프로덕션 배포 시 서버 프록시 권장) |
| 반응형 | `max-width: 100%` 설정으로 모바일 화면 대응 |
| 접근성 | 버튼에 `title` 속성 제공, 의미 있는 텍스트 레이블 사용 |
| 호환성 | 모던 브라우저 (Chrome, Firefox, Edge, Safari 최신 버전) |

## 6. API 명세

### 6.1 사용 엔드포인트

| API | URL 패턴 | 용도 |
|---|---|---|
| Current Weather | `/data/2.5/weather?q={city}&appid={key}&units=metric&lang=kr` | 현재 날씨 |
| Current Weather (좌표) | `/data/2.5/weather?lat={lat}&lon={lon}&appid={key}&units=metric&lang=kr` | 위치 기반 날씨 |
| 5 Day Forecast | `/data/2.5/forecast?q={city}&appid={key}&units=metric&lang=kr` | 5일 예보 |

### 6.2 API 키 발급 방법
1. [openweathermap.org](https://openweathermap.org) 회원가입
2. 상단 메뉴 **My API Keys** 탭에서 키 복사
3. 발급 후 활성화까지 최대 10분 소요
4. `weather-app.html` 내 `const API_KEY = 'YOUR_API_KEY'` 교체

## 7. 오류 처리

| 상황 | 처리 방식 |
|---|---|
| API 키 미설정 | "API 키를 먼저 설정해 주세요." |
| 존재하지 않는 도시 | "도시를 찾을 수 없습니다." |
| 네트워크 오류 | "네트워크 오류가 발생했습니다." |
| 위치 권한 거부 | "위치 정보를 가져올 수 없습니다." |
| Geolocation 미지원 | "이 브라우저는 위치 기능을 지원하지 않습니다." |
